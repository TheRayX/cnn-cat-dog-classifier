# Cat vs Dog Classification using CNN

A deep learning project that uses a **Convolutional Neural Network (CNN)** to classify images as either cats or dogs.

## Overview

This project demonstrates a binary image-classification workflow using a CNN.

The model learns visual patterns from labeled cat and dog images and uses those learned features to classify previously unseen images.

The project provides practical experience with image preprocessing, CNN architecture, model training, and image classification.
